# Invisible Text Steganography

This project hides secret messages inside normal text using invisible Unicode characters.

## Features
- Hide secret messages
- Reveal hidden messages
- Uses invisible Unicode symbols

## Files
- encode.py → hides secret
- decode.py → reveals secret

## Language
Python

## How to Run

### Encode Message
```bash
python encode.py

### Decode Message
```bash
python decode.py
